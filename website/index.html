Architecture diagram · Home Assistant changes allow-listed image selections through the ESPHome API. The direct display path does not make a local HTTP round trip.

Less duplication. More display.

One image.
Every widget.

Widgets displaying the same SD path share one decoded RGB565 buffer. LVGL draws that source at each widget’s size with contain, cover, or stretch.

Default decoded cache budget1MB

Allocated on demand in PSRAM.
Configurable from 0 to 4 MB.

Cache what you use

LRU eviction releases inactive frames. Images still assigned to widgets remain protected, including widgets on hidden pages.

Choose the right fallback

Unscaled widgets can stream from SD when caching fails. Fitted widgets need a decoded cache entry and keep their previous image if it cannot be created.

Know the memory cost

A 320 × 480 RGB565 source uses 307,200 bytes. Drawing it smaller does not shrink that allocation or eliminate scaling work.

Know what you’re building on

Implemented. Tested.
Still to explore.

Implementation is verified against the component source. Hardware results below are maintainer reports for the FNK0104S, not independent testing or a claim of universal support.

Hardware tested

Basic operation confirmed

  • Web uploads, downloads, folders, and deletion
  • SD image display, memory usage, and HA Selects
  • Hidden image status/action and fitted image scaling (October 10, 2026)
  • HA PSRAM diagnostics and unused-cache release, including assigned images on hidden pages (October 12, 2026)
Testing pending

Failure and stress scenarios

  • Concurrent clients and conflicting operations
  • Operator mistakes and interrupted transfers
  • Power loss, SD corruption, and card failure
  • Reconnect, migration, stress, and endurance checks

Staging, recovery, and reader protection are implemented safeguards; these do not establish proven recovery in every failure scenario.

Planned only

Beyond the current scope

  • Directory / wildcard image sources
  • A Home Assistant image-library refresh button
  • Optional SD MP3 playback

These are documented plans, not current features or delivery commitments. Image names and paths are currently compiled into firmware.

One documented hardware target. A trusted LAN only.

Freenove FNK0104S / ESP32-S3R8 with four-bit SDMMC and octal PSRAM. Other boards, Arduino, SPI SD, hotplug, TLS, and public internet exposure are unsupported. PNG and progressive JPEG cannot render through the direct SD image path. FAT recovery cannot guarantee protection against power loss or card failure. Keep backups.
